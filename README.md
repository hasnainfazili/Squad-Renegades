# Squad Renegades
An Unreal Engine 5 project, a 5v5 Player V/S Player (PvP) competitive racing shooter game.
This is my first Unreal Engine 5 project after having worked with Unity for a long time. This was first and foremost done to learn and get used to the engine.
The vehicles are made using the Chaos Vehicle Plugin with the added functionality of shooting bullets, rockets and lasers all implemented from scratch using Blueprints and Niagra VFX system. 
The Project also introduced me to Unreal's Multiplayer solution, with which due my lack of knowledge was troublesome to operate with some PC's not allowing it to conenct to Servers or just not allowing it go through firewalls, overall really showed how smoothly you can get a prototype up and running without the overhead of worrying about setting up servers or rooms for Multiplayer.
