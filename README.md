# Squad Renegades
An Unreal Engine 5 project, a 5v5 Player V/S Player (PvP) competitive racing shooter game.

## How to Play
Clone the repository:
```bash 
git clone https://github.com/hasnainfazili/Squad-Renegades
```
Open the uproject file inside Unreal Engine 5.4

... that's all and just press play.
